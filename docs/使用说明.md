# 使用说明

## 安装

```xml
<PackageReference Include="AssemblyMeta" Version="0.1.0" />
```

只需要其中一块时，改引用 `AssemblyMeta.AssemblyInfo`、`AssemblyMeta.Constants`、`AssemblyMeta.Project`、`AssemblyMeta.Metadata` 或 `AssemblyMeta.Git`。

## 生成入口

默认是全局命名空间的 `internal static partial class AssemblyMeta`。

| 属性 | 作用 |
|---|---|
| `AssemblyMetaNamespace` | 根命名空间。空则全局。 |
| `AssemblyMetaVisibility` | `internal`（默认）或 `public`。`public` 时成员为 `static readonly`。 |

## AssemblyInfo

```csharp
Console.WriteLine(AssemblyMeta.Info.Version);
Console.WriteLine(AssemblyMeta.Info.InformationalVersion);
```

九个成员总会生成。空字符串表示对应 MSBuild 属性没有值。`Version` 是程序集版本，例如 `1.2.3.0`，不是 `1.2.3-beta.4`。

## Constants

```xml
<PropertyGroup>
  <HttpDefaultTimeoutSeconds>10</HttpDefaultTimeoutSeconds>
</PropertyGroup>
<ItemGroup>
  <Constant Include="Http.TimeoutSeconds" Value="$(HttpDefaultTimeoutSeconds)" Type="int" Comment="请求超时（秒）" />
  <FileConstant Include="@(Content)" />
</ItemGroup>
```

```csharp
var timeout = TimeSpan.FromSeconds(AssemblyMeta.Constants.Http.TimeoutSeconds);
var license = AssemblyMeta.Constants.Content.Docs.License;
```

点号会变成嵌套类型。非法标识符会被折叠成下划线，C# 关键字加 `@`。同名冲突报告 `AM0001`。

`FileConstant` 的常量值使用正斜杠，便于确定性构建。例如 `Content/Docs/License.md` 对应 `AssemblyMeta.Constants.Content.Docs.License`。

多行字符串在语言版本 ≥ 11 时使用 raw string literal，否则使用转义字符串。

## Project

```xml
<PropertyGroup>
  <Foo>Bar</Foo>
  <ProjectProperty>Foo;Configuration</ProjectProperty>
</PropertyGroup>
<ItemGroup>
  <ProjectProperty Include="Company" Comment="公司名称" />
</ItemGroup>
```

```csharp
var company = AssemblyMeta.Project.Company;
```

`$(ProjectProperty)` 按分号拆分，file-based apps 写 `#:property ProjectProperty=Foo`。默认还会带上 `AssemblyName`、`RootNamespace` 和目标框架相关属性。

## Metadata

```xml
<ItemGroup>
  <AssemblyMetadata Include="DemoKey" Value="Bar" />
</ItemGroup>
```

```csharp
var value = AssemblyMeta.Metadata.DemoKey;
```

SDK 仍会把同一项写成 `AssemblyMetadataAttribute`。本包只读该项，不重复生成特性。源码里手写的特性不会出现在 `AssemblyMeta.Metadata`。

## Git

```csharp
var commit = AssemblyMeta.Git.Commit;
var sha = AssemblyMeta.Git.Sha;
var root = AssemblyMeta.Git.Root;
var branch = AssemblyMeta.Git.Branch;
```

`Sha` 是 `Commit` 的前 9 位。`Root` 使用正斜杠并以斜杠结尾。`Url` 仅在 `PublishRepositoryUrl=true` 或已设置 `RepositoryUrl` 时填充。分支优先读 CI 环境变量（GitHub Actions、Azure DevOps、GitLab、AppVeyor、TeamCity、Travis、CircleCI、Jenkins、Buddy）；拉取请求记为 `pr` 加编号，例如 `pr15`。没有 CI 时回落到 SourceLink 分支或 `.git/HEAD`。

设计时构建默认不查询。五个常量都是 `[pending build]`。要在设计时填充，显式设置 `EnableSourceControlManagerQueries=true`。

下游 targets 可以 `DependsOnTargets="InitializeGitInformation"`，读取 `RepositoryCommit`、`RepositorySha`、`RepositoryRoot`、`RepositoryUrl`、`RepositoryBranch`。

.NET 8+ SDK 已内置 SourceLink，不必再引用 `Microsoft.SourceLink.*`。
