# 使用说明

## 安装

```xml
<PackageReference Include="AssemblyMeta" Version="1.1.0" />
```

只需要其中一块时，改引用 `AssemblyMeta.AssemblyInfo`、`AssemblyMeta.Constants`、`AssemblyMeta.Project`、`AssemblyMeta.Metadata`、`AssemblyMeta.Git`、`AssemblyMeta.Resources` 或 `AssemblyMeta.Strings`。

生成只发生在写下这条 `PackageReference` 的项目里。再引用该项目的下一个项目不会看到这些成员。

许可是 MIT。没有维护费。安装时不要求接受另一份许可。

编译器 API 下限是 4.11.0。SDK 10.0.303 是验证环境，编译期不另做版本检查。

## 生成入口

未设置 `AssemblyMetaNamespace` 时，根类放在项目的 `$(RootNamespace)` 里。SDK 没写这个属性时，它等于项目名。把 `AssemblyMetaNamespace` 显式设成空白时，根类在全局命名空间。默认可见性是 `internal static partial class AssemblyMeta`。

| 属性 | 作用 |
|---|---|
| `AssemblyMetaNamespace` | 根类的命名空间。不写则用 `$(RootNamespace)`。显式空白则全局。MSBuild 不区分大小写，`AssemblyMetaNameSpace` 是同一个属性。 |
| `AssemblyMetaVisibility` | `internal`（默认）或 `public`。`internal` 时只有合格类型是 `const`，其它类型是 `static readonly`。`public` 时成员为 `static readonly`，不能写进特性参数。调用处仍是 `AssemblyMeta.名字`。 |

非法命名空间会警告 `AM0005` 并回退到全局命名空间，不会把原字符串写进生成源码。

下文示例写成 `AssemblyMeta.名字`。代码如果已经在 `RootNamespace` 里，可以直接写。顶层语句不在那个命名空间里，需要 `using`，或者把属性设成空白：

```xml
<PropertyGroup>
  <AssemblyMetaNamespace></AssemblyMetaNamespace>
</PropertyGroup>
```

空白可以写在项目文件、`Directory.Build.targets`，或命令行 `/p:AssemblyMetaNamespace=`。`Directory.Build.props` 早于本包的 props，写在那里的空值会被当成未设置。

`RootNamespace` 的第一段如果就是 `AssemblyMeta`，C# 会把 `AssemblyMeta.Info` 当成命名空间。这时改用 `global::根命名空间.AssemblyMeta`，或把属性设成空白。

## AssemblyInfo

```csharp
Console.WriteLine(AssemblyMeta.Info.Version);
Console.WriteLine(AssemblyMeta.Info.InformationalVersion);
```

九个成员总会生成。生成器读到空字符串就写空字符串。使用 Microsoft.NET.Sdk 时，SDK 会先把空的 `Authors` 设成程序集名，再把空的公司设成 `Authors`，并把空的标题和产品设成程序集名。说明和版权未设置时仍是空字符串。`Version` 是程序集版本，例如 `1.2.3.0`，不是 `1.2.3-beta.4`。

从 ThisAssembly 迁过来时有三处不同。这九个成员总会在。公司、产品和标题在 `Authors` 也未设置时等于程序集名。只设置了 `Authors` 时，公司等于 `Authors`，标题和产品仍是程序集名。这是 SDK 先填的，不是本包回填的。商标以及其他程序集特性不生成成员。

## Constants

```xml
<PropertyGroup>
  <HttpDefaultTimeoutSeconds>10</HttpDefaultTimeoutSeconds>
</PropertyGroup>
<ItemGroup>
  <Constant Include="Http.TimeoutSeconds" Value="$(HttpDefaultTimeoutSeconds)" Type="int" Comment="请求超时（秒）" />
  <FileConstant Include="@(Content)" />
</ItemGroup>
```

```csharp
var timeout = TimeSpan.FromSeconds(AssemblyMeta.Constants.Http.TimeoutSeconds);
var license = AssemblyMeta.Constants.Content.Docs.License;
```

点号会变成嵌套类型。非法标识符会被折叠成下划线，C# 关键字加 `@`。同名冲突报告 `AM0001`。

`FileConstant` 的常量值使用正斜杠，便于确定性构建。例如 `Content/Docs/License.md` 对应 `AssemblyMeta.Constants.Content.Docs.License`。

多行字符串在语言版本 ≥ 11 时使用 raw string literal，否则使用转义字符串。

## Project

```xml
<PropertyGroup>
  <Foo>Bar</Foo>
  <ProjectProperty>Foo;Configuration</ProjectProperty>
</PropertyGroup>
<ItemGroup>
  <ProjectProperty Include="Company" Comment="公司名称" />
</ItemGroup>
```

```csharp
var company = AssemblyMeta.Project.Company;
```

`$(ProjectProperty)` 按分号拆分，file-based apps 写 `#:property ProjectProperty=Foo`。默认还会带上 `AssemblyName`、`RootNamespace`、`TargetFrameworkIdentifier`、`TargetFrameworkMoniker`、`TargetFrameworkVersion`、`RuntimeIdentifier`、`RuntimeIdentifiers`。其中标识符、Moniker 和版本构成目标框架标识。要 `net8.0` 这种目标框架短名，再点名 `TargetFramework`。点号变成嵌套类型。Debug/Release 也可以读 `AssemblyMeta.Info.Configuration`。

## Metadata

```xml
<ItemGroup>
  <AssemblyMetadata Include="DemoKey" Value="Bar" />
</ItemGroup>
```

```csharp
var value = AssemblyMeta.Metadata.DemoKey;
```

点号变成嵌套类型。SDK 仍会把同一项写成 `AssemblyMetadataAttribute`。本包只读该项，不重复生成特性。源码里手写的特性不会出现在 `AssemblyMeta.Metadata`。

## Git

```csharp
var commit = AssemblyMeta.Git.Commit;
var sha = AssemblyMeta.Git.Sha;
var root = AssemblyMeta.Git.Root;
var branch = AssemblyMeta.Git.Branch;
```

`RepositorySha` 已有值时，`Sha` 原样采用。否则 `Sha` 是 `Commit` 的前 9 位；不足 9 位时用全长。`Root` 使用正斜杠，非空时以斜杠结尾。`Url` 仅在 `PublishRepositoryUrl=true` 或已设置 `RepositoryUrl` 时填充。`RepositoryBranch` 已有值时原样采用。否则优先读 CI 环境变量（GitHub Actions、Azure DevOps、GitLab、AppVeyor、TeamCity、Travis、CircleCI、Jenkins、Buddy）；拉取请求记为 `pr` 加编号，例如 `pr15`。Azure DevOps 读 PR 号，Jenkins 读 `CHANGE_ID`。没有 CI 时回落到 SourceLink。查询已打开且仍没有分支时，才读仓库根上的 `.git/HEAD`。

设计时构建默认不查询。五个常量都是 `[pending build]`。设计时若 `EnableSourceControlManagerQueries` 为空，会写成 `false`。要在设计时填充，显式设置 `EnableSourceControlManagerQueries=true`。

下游 targets 可以 `DependsOnTargets="InitializeGitInformation"`，读取 `RepositoryCommit`、`RepositorySha`、`RepositoryRoot`、`RepositoryUrl`、`RepositoryBranch`。

.NET 8+ SDK 已内置 SourceLink，不必再引用 `Microsoft.SourceLink.*`。查询已打开且没有提交号时，警告 `AM0006`。五个占位值不触发这条警告。

## Resources

```xml
<ItemGroup>
  <EmbeddedResource Include="Content/Docs/License.md" />
</ItemGroup>
```

```csharp
var text = AssemblyMeta.Resources.Content.Docs.License.Text;
var bytes = AssemblyMeta.Resources.Content.Docs.License.GetBytes();
using var stream = AssemblyMeta.Resources.Content.Docs.License.GetStream();
```

嵌套名与 `FileConstant` 相同：相对路径去掉扩展名，点号分层。每个纳入的资源都有 `Text`。运行时按 SDK 写入的清单资源名精确打开流。`Text` 用 UTF-8 读取并缓存。`GetBytes` 和 `GetStream` 每次重新打开，调用方释放 `GetStream` 返回的流。二进制内容用 `GetBytes` 或 `GetStream`。

`.resx` 默认交给 Strings。`AssemblyMetaResource=false` 排除某一项；`AssemblyMetaResource=true` 把 `.resx` 编译后的清单项也放进来。要让动态加入的文件参与生成，在 `PrepareResourceNames` 之前把它加进 `EmbeddedResource`。从别的时点迁过来时，把 `BeforeTargets` 改到 `PrepareResourceNames`。

与外层类型同名的路径片段会在末尾加下划线并报告 `AM0008`。例如 `Resources/readme.txt` 变成 `AssemblyMeta.Resources.Resources_.readme`，`Docs/Docs/file.txt` 变成 `AssemblyMeta.Resources.Docs.Docs_.file`。叶子名如果是 `Text`、`GetBytes` 或 `GetStream`，根片段如果是 `Manifest`，也会同样改写。没有清单名报告 `AM0009`，无法映射为标识符报告 `AM0010`。

## Strings

作为 `EmbeddedResource` 的中性 `.resx` 会生成编译期常量。默认 `internal` 时是 `const`，可以写进特性参数；`AssemblyMetaVisibility=public` 时是 `static readonly`，不能写进特性参数。SDK 默认把 `**/*.resx` 收进 `EmbeddedResource`。`Strings.fr.resx` 这类卫星文件不参与生成。

```csharp
var hello = AssemblyMeta.Strings.Hello;
var stock = AssemblyMeta.Strings.Shopping.OutOfStock;
```

键名里的 `_` 和 `.` 都会变成嵌套类型。路径末尾连续的 `Strings` 段都会去掉，避免再套一层 `Strings`。`Strings/Strings.resx` 的键直接挂在 `AssemblyMeta.Strings` 下。与外层类型同名的片段在末尾加下划线并报告 `AM0008`，键 `Strings` 是 `AssemblyMeta.Strings.Strings_`。根上的 `Strings.resx` 键直接挂在 `AssemblyMeta.Strings` 下；`UI/Strings.resx` 的 `Hello` 是 `AssemblyMeta.Strings.UI.Hello`。其它文件带上相对路径，例如 `Errors.resx` 的 `NotFound` 是 `AssemblyMeta.Strings.Errors.NotFound`。

`{0}` 仍留在字符串里，不会变成格式化方法。带 `type` 或 `mimetype` 的非字符串项会跳过，并报告 `AM0007`。无效键报告 `AM0010`。无法读取或无法解析 resx 报告 `AM0011`。`AssemblyMetaStrings=false` 可排除某个 resx。

resx 作为 `AdditionalFiles` 交给生成器直读。IDE 里修改并保存 resx 后，`AssemblyMeta.Strings` 即时刷新，不等下一次构建。

## 诊断

| 码 | 何时出现 |
|---|---|
| `AM0001` | 重名 |
| `AM0002` | 名称无效 |
| `AM0003` | 非字符串常量为空 |
| `AM0004` | 载荷损坏 |
| `AM0005` | 命名空间无效 |
| `AM0006` | 查询已打开且没有 Git 提交号（警告） |
| `AM0007` | resx 非字符串项被跳过（警告） |
| `AM0008` | 名称与外层类型或生成成员冲突后已改写（警告） |
| `AM0009` | 嵌入资源没有清单名（MSBuild 警告） |
| `AM0010` | 无法映射为成员（警告；Resources 侧为 MSBuild 警告） |
| `AM0011` | resx 无法读取或解析（错误） |
| `AM0012` | 无法识别的 AssemblyMetaVisibility，已回退 internal（警告，仅 Strings） |

## 从 ThisAssembly 迁过来

根类名是 `AssemblyMeta`。命名空间属性是 `AssemblyMetaNamespace`：不写则用 `RootNamespace`，显式空白则全局。可见性属性是 `AssemblyMetaVisibility`。`public` 成员是 `static readonly` 字段，不能写进特性参数。`FileConstant` 的常量值用正斜杠。resx 键会带上路径前缀，末段名为 `Strings` 时去掉这一段。动态嵌入资源要在 `PrepareResourceNames` 之前加入。
