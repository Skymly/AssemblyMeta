# 契约

1.0.0 的调用方表面。包版本只有 `Directory.Build.props` 里的 `AssemblyMetaPackageVersion` 这一处来源，值为 `1.0.0`。

## 根形状

默认生成全局命名空间里的 `internal static partial class AssemblyMeta`。调用方可以再写同一个 partial。

| 属性 | 作用 |
|---|---|
| `AssemblyMetaNamespace` | 根类的命名空间。空则全局。非法值警告 `AM0005` 并回退，不把原字符串写进生成源码。 |
| `AssemblyMetaVisibility` | `internal`（默认）或 `public`。`public` 时原来的 `const` 改成 `static readonly` 字段，不能写进特性参数。 |

只生成 C#。不按语言分派。

生成器只出现在写下 `PackageReference` 的项目里。

## 成员

`Version` 取 `AssemblyVersion`，不是 NuGet 包版本。

### AssemblyInfo

`AssemblyMeta.Info` 下九个 `string`：`Configuration`、`Company`、`Title`、`Description`、`Product`、`Copyright`、`Version`、`InformationalVersion`、`FileVersion`。九个成员总会生成。没有值时是空字符串，不回填程序集名。不生成商标或其他程序集特性。`GenerateAssemblyInfo=false` 时这九个常量仍会生成。

准备目标读取：`Configuration`、`Company`、`AssemblyTitle`、`Description`、`Product`、`Copyright`、`AssemblyVersion`、`InformationalVersion`、`FileVersion`。

### Constants

项 `Constant`：`Include` 是名字，`Value`、`Type`、`Comment` 可选。不写 `Type` 时是 `string`。成员挂在 `AssemblyMeta.Constants` 上。点号变成嵌套类型。非法标识符字符折叠成下划线，连续的收成一个。C# 关键字加 `@`。同名既是成员又是嵌套类型时报告 `AM0001` 并跳过。

`FileConstant` 收项目内文件或带 `Link` 的文件。相对路径去掉扩展名后按分隔符分层，常量值用正斜杠。`Content/Docs/License.md` 的成员是 `AssemblyMeta.Constants.Content.Docs.License`。

### Project

成员是 `string`，挂在 `AssemblyMeta.Project` 上。项 `ProjectProperty` 的 `Include` 是属性名，可选 `Comment`。属性 `$(ProjectProperty)` 按分号拆开，并入同一组。默认还有 `AssemblyName`、`RootNamespace`、`TargetFrameworkIdentifier`、`TargetFrameworkMoniker`、`TargetFrameworkVersion`、`RuntimeIdentifier`、`RuntimeIdentifiers`。其中标识符、Moniker 和版本构成目标框架标识。目标框架短名要另外点名 `TargetFramework`。

### Metadata

成员是 `string`，挂在 `AssemblyMeta.Metadata` 上。只读 MSBuild 项 `AssemblyMetadata` 的 `Include`、`Value`、`Comment`。源码里手写的特性不会出现。SDK 仍会把同一项写成特性，本包不改写该项。

### Git

`AssemblyMeta.Git` 只有五个 `string`：`Commit`、`Sha`、`Root`、`Url`、`Branch`。`Sha` 是 `Commit` 的前 9 位；不足 9 位时用全长。`Root` 用正斜杠，非空时以 `/` 结尾。`Url` 在 `RepositoryUrl` 已有值时用该值；否则仅当 `PublishRepositoryUrl` 为 true 时填充，再否则是空字符串。未打开查询时，五个生成值都是 `[pending build]`。写回 `RepositoryCommit`、`RepositorySha`、`RepositoryRoot`、`RepositoryUrl`、`RepositoryBranch` 的仍是解析结果，不把占位符写进去。

设计时若 `EnableSourceControlManagerQueries` 为空，会写成 `false`。要填充就显式设成 `true`。查询已打开且没有提交号时警告 `AM0006`。五个占位值不触发这条警告。

分支优先读 CI 变量。拉取请求记为 `pr` 加编号。Azure DevOps 读 PR 号，Jenkins 读 `CHANGE_ID`。没有 CI 时回落到 SourceLink 或 `.git/HEAD`。

下游可以 `DependsOnTargets="InitializeGitInformation"`，读取上述五个 `Repository*` 属性。`.NET 8` 起的 SDK 已内置 SourceLink，不必再引用 `Microsoft.SourceLink.*`。是否调用 `InitializeSourceControlInformation`，看 SDK 的 `SourceControlInformationFeatureSupported`。

### Resources

成员挂在 `AssemblyMeta.Resources` 上。相对路径去掉扩展名后按点号分层。每个纳入的嵌入资源都有 `public static string Text`、`public static byte[] GetBytes()`、`public static System.IO.Stream GetStream()`。`Text` 按 UTF-8 读取并缓存。后两个每次重新打开。清单名来自项上的 `ManifestResourceName`，运行时按生成期写死的这个名字打开。与 `Resources` 同名的路径片段，叶子名是 `Text`、`GetBytes` 或 `GetStream`，或根片段是 `Manifest`，会改成带下划线的名字并警告 `AM0008`。`.resx` 默认不进入 Resources。`AssemblyMetaResource=false` 排除一项；`AssemblyMetaResource=true` 把 `.resx` 编译后的清单项也放进来。动态加入的文件要在 `PrepareResourceNames` 之前放进 `EmbeddedResource`。

### Strings

成员挂在 `AssemblyMeta.Strings` 上。中性 `.resx` 生成编译期常量。项上 `WithCulture=true` 的卫星 resx 不参与。`{0}` 和具名占位符留在字面量里，不生成带参方法。键里的 `_` 和 `.` 分层。路径最后一段是 `Strings` 时去掉这一段。带 `type` 或 `mimetype` 的非字符串项跳过并警告 `AM0007`。`AssemblyMetaStrings=false` 可排除某个 resx。

## 诊断

| 码 | 何时出现 |
|---|---|
| `AM0001` | 重名 |
| `AM0002` | 名称无效 |
| `AM0003` | 非字符串常量为空 |
| `AM0004` | 载荷损坏 |
| `AM0005` | 命名空间无效 |
| `AM0006` | 查询已打开且没有 Git 提交号（警告） |
| `AM0007` | resx 非字符串项被跳过（MSBuild 警告） |
| `AM0008` | 名称与外层类型或生成成员冲突后已改写（警告） |
| `AM0009` | 嵌入资源没有清单名（MSBuild 警告） |
| `AM0010` | 无法映射为成员（MSBuild 警告） |
| `AM0011` | resx 无法读取或解析（MSBuild 错误） |

没有赞助检查、维护费或遥测。

## 增量输入

每个生成器的增量输入只有一条载荷字符串和 C# 语言版本。载荷键：

| 包 | 键 |
|---|---|
| `AssemblyMeta.AssemblyInfo` | `build_property.AssemblyMeta_AssemblyInfoPayload` |
| `AssemblyMeta.Constants` | `build_property.AssemblyMeta_ConstantsPayload` |
| `AssemblyMeta.Project` | `build_property.AssemblyMeta_ProjectPayload` |
| `AssemblyMeta.Metadata` | `build_property.AssemblyMeta_MetadataPayload` |
| `AssemblyMeta.Git` | `build_property.AssemblyMeta_GitPayload` |
| `AssemblyMeta.Resources` | `build_property.AssemblyMeta_ResourcesPayload` |
| `AssemblyMeta.Strings` | `build_property.AssemblyMeta_StringsPayload` |

缺载荷时不写文件、不报错。载荷无法解码时报告 `AM0004`，也不写文件。

## 包

| 包 ID | 作用 |
|---|---|
| `AssemblyMeta` | 元包，聚合下面七个 |
| `AssemblyMeta.AssemblyInfo` | 程序集信息 |
| `AssemblyMeta.Constants` | 常量与文件常量 |
| `AssemblyMeta.Project` | 项目属性 |
| `AssemblyMeta.Metadata` | `AssemblyMetadata` 项 |
| `AssemblyMeta.Git` | Git 五个成员 |
| `AssemblyMeta.Resources` | 嵌入资源 |
| `AssemblyMeta.Strings` | resx 常量 |

七个子包带 `analyzers/dotnet/cs`、`tasks/netstandard2.0`、`buildTransitive`。元包只聚合这七个依赖。没有包图标，没有符号包。许可是 MIT。

调用方需要能提供增量生成器的编译器。本仓库写下的编译器 API 下限是 4.11.0。SDK 10.0.303 是验证环境。编译期不另做版本检查。

## 1.0 之后

`1.0.0` 冻结上面的名字、九个程序集信息字段、Git 的五个成员，以及 `public` 时的 `static readonly` 字段。

加成员、加诊断码，可以是次版本。改名、删成员、把 `const` 换成字段或反过来、把 `static readonly` 字段换成属性、把占位符改成带参方法、把空字符串改成缺成员，都是破坏性变更。编译器 API 下限升高也是破坏性变更。验证用的 SDK 可以更换，不单独升主版本。
