# 架构

## 项目

| 项目 | 角色 |
|---|---|
| `AssemblyMeta.Core` | 模型、Base64 载荷、标识符消毒、C# emitter。不引用 Roslyn。 |
| `AssemblyMeta.Tasks` | MSBuild 任务，把属性和项编码成载荷。 |
| `AssemblyMeta.*.Generator` | `netstandard2.0` 增量生成器，只引用 `Microsoft.CodeAnalysis.CSharp`。 |
| `AssemblyMeta.*` | 打包项目：analyzer dll + `buildTransitive` props/targets。 |
| `AssemblyMeta` | 元包，依赖 AssemblyInfo、Constants、Project、Metadata、Git、Resources、Strings，并允许分析器流向直接消费者。 |

## 数据通道

```
props/targets
  → CompilerVisibleProperty / CompilerVisibleItemMetadata
  → 生成的 .editorconfig（build_property.* / build_metadata.*）
  → IIncrementalGenerator
  → C# emitter
```

Roslyn 目前不能在没有源文件或 `AdditionalFiles` 的情况下枚举 `build_metadata.*`（[dotnet/roslyn#60595](https://github.com/dotnet/roslyn/issues/60595)）。因此 M1 不使用 `AdditionalFiles`。targets 仍声明 `CompilerVisibleItemMetadata`，真正的数据放在单个 `CompilerVisibleProperty` 里：

- `AssemblyMeta_AssemblyInfoPayload`
- `AssemblyMeta_ConstantsPayload`
- `AssemblyMeta_ProjectPayload`
- `AssemblyMeta_MetadataPayload`
- `AssemblyMeta_GitPayload`
- `AssemblyMeta_ResourcesPayload`
- `AssemblyMeta_StringsPayload`

值是 UTF-8 长度前缀格式的 Base64。这样换行、`#`、分号和引号不会被 editorconfig 截断。生成器的增量输入就是这根字符串加上 `ParseOptions.LanguageVersion`，源码变化不会击穿缓存。

`AssemblyInfo` 的准备目标依赖 `GetAssemblyAttributes`，所以 `AssemblyVersion`、`FileVersion`、`InformationalVersion` 与 SDK 推导结果一致，包括 SourceLink 追加的修订号。`GenerateAssemblyInfo=false` 时属性仍按 MSBuild 值生成。

`Project` 在生成 editorconfig 前把 `@(ProjectProperty)` 与 `$(ProjectProperty)` 求值后编码。`Metadata` 只读取 `@(AssemblyMetadata)`，不添加、不删除、不改写，因此 SDK 仍会把同一项写成程序集特性。`Git` 的 `InitializeGitInformation` 依赖 SDK 内置的 `InitializeSourceControlInformation`，再把 `RepositoryCommit` / `RepositorySha` / `RepositoryRoot` / `RepositoryUrl` / `RepositoryBranch` 交给下游。设计时构建把 `EnableSourceControlManagerQueries` 留空时写成 `false`，生成器收到占位符 `[pending build]`。

`Resources` 在 `PrepareResourceNames` 之后读取 `ManifestResourceName`，生成 `Text`、`GetBytes` 和 `GetStream`。`.resx` 默认不进入 Resources。`Strings` 读取中性 resx 源文件，卫星文件（`WithCulture=true`，或 `WithCulture` 为空且文件名带文化名）跳过，值是编译期常量。

诊断码：`AM0001` 重名，`AM0002` 名称无效，`AM0003` 非字符串常量为空，`AM0004` 载荷损坏，`AM0005` 命名空间无效，`AM0006` Git 提交号缺失（警告），`AM0007` resx 非字符串项被跳过（MSBuild 警告），`AM0008` 名称与外层类型或生成成员冲突后已改写（警告），`AM0009` 嵌入资源没有清单名（MSBuild 警告），`AM0010` 无法映射为成员（MSBuild 警告），`AM0011` resx 无法读取或解析（MSBuild 错误）。

## 多语言

只生成 C#。载荷到源码不按语言分派。见 [不为 C# 发射保留语言 seam](adr/0002-no-language-seam-for-source-emission.md)。

## 打包

每个子包包含：

- `analyzers/dotnet/cs/*.dll`：生成器与 `AssemblyMeta.Core`
- `tasks/netstandard2.0/*.dll`：MSBuild 任务与 `AssemblyMeta.Core`
- `buildTransitive/{PackageId}.props`
- `buildTransitive/{PackageId}.targets`

元包对子包使用 `PrivateAssets=none`，nuspec 不排除 analyzers。子包 props 再把直接引用标成 `PrivateAssets=all`，避免分析器继续向外传递。包本身标记 `developmentDependency`。
